## 🚀 セットアップ手順

### 1. 環境変数設定

```bash
cp ~/.../kindle_monitor/.env.kindle.template ~/.env.kindle
nano ~/.env.kindle  # API キーを入力
chmod 600 ~/.env.kindle
```

### 2. Cron 登録

```bash
crontab -e

# 以下を追加:
*/30 * * * * source ~/.env.kindle 2>/dev/null && python3 kindle_display_final_production.py >> /var/log/kindle_monitor.log 2>&1
```

### 3. ログ監視

```bash
tail -f /var/log/kindle_monitor.log
```

## 📞 トラブルシューティング

### よくある問題

| 問題 | 原因 | 解決方法 |
|------|------|--------|
| 時刻がはみ出す | フォント未対応 | 使用フォント確認 |
| カレンダー見えない | フォント小さすぎ | フォントサイズ確認 |
| API が「--」 | キー未設定 | `~/.env.kindle` 確認 |
| グラフがない | データ蓄積不足 | 数回実行待機 |

### 詳細は以下を参照

- トラブル → `README_FINAL.md`
- Cron → `CRON_UPDATE_FINAL.md`
- クイック → `START_HERE.md`
